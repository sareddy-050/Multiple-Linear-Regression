# Multiple Linear Regression

This project builds and evaluates Multiple Linear Regression models to predict Toyota Corolla car prices using vehicle attributes from the Toyota Corolla dataset.

## Topics Covered

* Loading and exploring the Toyota Corolla dataset
* Exploratory Data Analysis
* Descriptive statistics
* Missing value analysis
* Histograms
* Correlation heatmap
* Pair plot analysis
* Categorical feature encoding using LabelEncoder
* Feature and target selection
* Feature standardization using StandardScaler
* Train-test split
* Multiple Linear Regression
* Feature selection and model comparison
* Lasso Regression
* Ridge Regression
* Model coefficient analysis

## Models Developed

* Model 1: Multiple Linear Regression using all features
* Model 2: Multiple Linear Regression after removing `KM`
* Model 3: Multiple Linear Regression after removing `Gears`
* Lasso Regression
* Ridge Regression

## Model Evaluation

The regression models are evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score

The project also compares regression coefficients across Linear Regression, Lasso, and Ridge models.
